# Éditeur PDF

Éditeur PDF qui tourne entièrement dans le navigateur : aucun fichier n'est envoyé sur un serveur.

- Ajouter du texte, modifier un texte existant du PDF
- Surligner, dessiner, encadrer, masquer une zone
- Signer, insérer des images
- Tourner, réordonner, dupliquer, supprimer des pages, ajouter des pages blanches
- Fusionner plusieurs PDF, annuler / rétablir, télécharger le résultat

Bibliothèques incluses dans `lib/` : [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174 (Apache 2.0) et [pdf-lib](https://pdf-lib.js.org/) 1.17.1 (MIT).
